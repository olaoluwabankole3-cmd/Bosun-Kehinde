# Bosun Kehinde — Professional Portfolio

A premium, content-led professional portfolio for Olatunbosun Adura Kehinde.

Built with Next.js, TypeScript, responsive CSS, accessible navigation, and motion-enhanced storytelling.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Content safeguards

Information has been drafted from supplied CV, personal statement, facilitation and testimonial documents. Public-facing claims and project imagery should be approved by Bosun. The contact form opens the visitor's email client; no contact data is collected or stored by this application.

## Pages

Home, About, Work, individual case studies, Leadership, Speaking, Contact.
